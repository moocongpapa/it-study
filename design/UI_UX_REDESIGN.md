# IT Atlas UI/UX 정리 · 2026-10-22

## 목표와 범위

비전공자가 주제를 고르고, 그림과 글을 읽고, 직접 연습하는 흐름을 짧게 만든다. 기존의 밝은 학습 화면을 유지하면서 종이색 배경·진한 녹색 강조·일관된 글자와 간격을 사용한다. 학습 그래프, 대형 통계 카드, 본문을 가리는 하단 고정 바는 추가하지 않는다.

변경 범위: 공통 메뉴, 학습 목록과 추천 과정, 검색·필터, 아티클 리더, 완료 버튼, 튜터의 표시 스타일, 내 학습, 실무 연습실, 로그인. DB, 인증 방식, 채점, 학습 완료와 퀴즈 통과의 구분, 콘텐츠 API 캐시는 유지한다.

## 적용한 스킬과 기준 이미지

- 스킬: Uizze **ui-taste 0.3.0**, 공식 `https://uizze.sh/.well-known/skills/index.json` 배포.
- 공식 배포의 18개 파일을 받아 `CHECKSUMS.sha256`에 있는 해시와 비교했다. 게시자 체크섬 확인이며 독립적인 보안 인증을 의미하지 않는다.
- 설치: `~/.codex/skills/ui-taste`. 유료 MCP·별도 서비스·추가 npm 의존성은 설치하지 않았다.
- 읽은 지침: SKILL, image-to-ui, operate, distill, craft.
- 기준 이미지: [ui-taste-target.png](ui-taste-target.png), **1536×1024px**. 내장 image_gen으로 UI 구현 전에 생성하고 확인했다.
- 생성 의도: IT Atlas의 한국어 학습 목록. 밝은 종이색, 진한 녹색, 간결한 왼쪽 탐색, 세 추천 과정, 두 열의 분야별 목록. 그래프·대형 통계·장식적 배경을 제외하고 실제 읽기 동선을 중심으로 구성.
- 생성본의 예시 제목·시간은 데이터의 근거가 아니다. 구현에서는 실제 130개 토픽의 제목·요약·난이도·시간을 사용한다.
- 기준 이미지와 실제 화면을 같은 크기로 확인했다. 검색을 목록의 필터 옆에 배치하고 실제 한국어 글줄·44px 터치 영역을 확보했다. 픽셀 단위 동일성을 주장하지 않는다.
- 폰트는 기존 시스템 한글 폰트 스택을 사용한다. 외부 웹폰트 요청이나 추가 폰트 파일이 없다.

## 화면별 변경

| 화면 | 변경 이유와 구현 |
|---|---|
| 공통 메뉴 | 224px 사이드바, 세 학습 메뉴, 접을 수 있는 분야 묶음. 긴 분야명은 메뉴에서 짧게 표시하고 상세 제목은 보존 |
| 모바일 | 세 주요 메뉴를 상단에 노출. 페이지 헤더는 스크롤과 함께 사라지며 하단 고정 UI 없음 |
| 목록 | 반복 소개·총 학습시간·완료 통계 제거. 입문/AI/프로젝트 과정에 바로 진입. 큰 화면은 분야 두 열, 모바일은 한 열 |
| 검색 | 분야·과정·난이도를 검색 옆에 배치. 검색어 지우기, 빈 결과 안내와 초기화, `/`·Cmd/Ctrl+K 지원. 리더 안에서는 전역 검색 단축키를 가로채지 않음 |
| 리더 | 최대 폭 820px, 본문 좌우 여백 조정. 48px 툴바와 네 단계 탭만 고정. 완료/퀴즈/수업 안내는 본문 흐름 안에 배치 |
| 내 학습 | 통계의 시각적 비중 축소. 첫 이용자에게 학습 시작 버튼, 복습 없는 기존 이용자에게 연습실 안내. 계정과 브라우저 기록의 차이 명시 |
| 연습실 | 자료→결과물 관계를 표시하는 행 구성. 실습 상세에 자료/판단/작성 앵커 이동, 이동한 제목에 키보드 포커스 지원 |
| 로그인·튜터 | 공통 강조색과 버튼·입력 스타일 적용. 이메일 입력 16px, 의미 없는 전공자 수준 보장 문구 제거 |

## 접근성과 상태

- 본문 바로가기, 필드 접근성 이름, 현재 메뉴, 선택 과정, 완료 여부, 탭 상태를 유지한다.
- 주요 터치 영역은 44px. 좁은 화면에서 제목은 줄바꿈하고 보조 요약만 말줄임한다.
- 키보드 포커스 표시와 reduced-motion 설정을 지원한다. 튜터 자동 스크롤도 reduced-motion을 따른다.
- 검색 빈 결과, 리더 로딩/오류 재시도, 저장 중/실패, 로그인 필요 안내와 실습 저장 안내를 유지한다.

## 검증

- 타입 검사, ESLint, Next.js 프로덕션 빌드 통과.
- `practice:verify`: 세 실습, 자료/토픽 링크, 선택지별 해설, SSR, 손상된 초안, 입력 길이, Markdown 내보내기 검증 통과.
- `completion:verify`: 완료·취소, 반복 요청, 복습 일정, 채점 분리, RLS 소유권과 세션 검사 통과.
- `loading:verify`: 중복 요청 방지, 캐시/TTL, 재시도, 비공개·오류 콘텐츠 미캐시 검증 통과.
- 브라우저에서 AI 추천 과정의 순서, 검색 빈 결과·초기화, 분야 이동, 모바일 메뉴, 리더 완료·취소, 단계 전환, 큰 글씨, 비로그인 튜터 안내를 확인했다.
- 390×844 모바일 리더 측정: 툴바 48px + 단계 탭 45px, 본문 스크롤 **751px**. 브라우저 뷰포트 기준이며 실제 기기 주소창·키보드·safe-area 크기는 다를 수 있다.
- 최종 1536×1024 데스크톱과 390×844·320×740 모바일 화면을 확인했다. 320px 필터/추천 과정 줄바꿈을 보정했으며 문서 가로 넘침은 없었다. 키보드 Tab으로 분야 선택에 이동하고 포커스 외곽선 표시를 확인했다.
- 로컬 브라우저 콘솔의 오류·경고는 없었다.
- 로컬은 체험 데이터. 실제 이메일 발송, 로그인 후 계정 동기화, 유료 AI 요청은 이번 UI 변경의 브라우저 검증 범위가 아니다.
