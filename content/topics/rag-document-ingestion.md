# RAG 문서 수집·청킹·권한·삭제

> **먼저 한 문장:** RAG 품질은 검색 전의 문서 추출·분할·버전·권한·삭제 처리부터 시작됩니다.

검색할 문서를 그냥 모아 두기만 하면 중복·오래된 내용·권한 문제가 답변으로 이어집니다. 자료를 받아 정리하고 검색에 넣는 준비 과정을 알아야 근거 있는 답을 만들 수 있습니다.

## 먼저 알아둘 말

```learning
{"slug":"rag-document-ingestion","view":"words"}
```

## 작은 예로 이해하기

도서관 규정을 검색용으로 잘라 저장할 때 ‘평일 운영시간’이라는 제목과 시간을 따로 떼면 뜻을 놓칠 수 있습니다. 문맥이 유지되도록 나누고 원본 문서와 버전을 기록합니다. 규정이 삭제되면 검색용 조각도 정리하고, 직원 전용 문서는 학생에게 검색되지 않도록 권한을 이어 줍니다.

## 익숙한 장면과 연결하기

도서관 책을 조각으로 복사할 때 제목·판본·열람 권한을 잃으면 어느 책인지, 읽어도 되는지 알 수 없습니다.

**비유의 한계 — 이 점은 달라요:** 청크를 작게 나누는 것이 항상 좋지는 않습니다. 표·절·예외가 분리되면 의미가 손상되고 원본 삭제가 복사본 삭제로 자동 이어지지도 않습니다.

## 직접 확인하기

문서·권한 → 분할·색인 → 갱신·삭제 순서로 읽어 보세요. 뒤의 과정에서 필요한 것이 앞에서 어떻게 준비되는지 찾습니다. 숫자는 읽는 순서이며 모든 상황이 정확히 세 단계라는 뜻은 아닙니다.
