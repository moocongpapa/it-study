# 환각·출처·모르는 답 처리

> **먼저 한 문장:** 자연스러운 문장과 근거 있는 답은 다르므로 주장별 출처와 모를 때의 행동을 검증해야 합니다.

그럴듯하게 틀린 답을 그대로 업무에 쓰면 문제가 커질 수 있습니다. 주장과 출처를 확인하고 모를 때 멈추는 경로를 두면 답변의 신뢰도를 더 구체적으로 점검할 수 있습니다.

## 먼저 알아둘 말

```learning
{"slug":"hallucination-grounding","view":"words"}
```

## 작은 예로 이해하기

AI가 ‘도서관은 일요일에도 연다’고 자연스럽게 답했지만 안내문에는 평일 시간만 있다고 합시다. 문장이 매끄러워도 일요일 운영을 뒷받침하는 근거는 없습니다. 출처에 실제로 적힌 내용인지 확인하고 없으면 ‘확인할 수 없다’고 답하도록 정해야 합니다.

## 익숙한 장면과 연결하기

확신 있게 발표하는 사람이 정확한 자료를 봤는지는 별개입니다. 발표에 붙은 참고문헌도 실제 주장을 뒷받침하는지 확인해야 합니다.

**비유의 한계 — 이 점은 달라요:** 출처 ID가 존재하거나 인용 형식이 맞아도 주장을 지지한다는 보장은 없습니다. 모델의 자신감 표현도 보정된 확률로 볼 수 없습니다.

## 직접 확인하기

사례가 근거 확인과 근거 없는 확신 중 어디에 해당하는지 골라 보세요. 고른 뒤 나오는 이유를 읽고, 같은 기준으로 다음 사례를 판단합니다.

```learning
{"slug":"hallucination-grounding","view":"explore"}
```
