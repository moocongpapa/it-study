# 표본·편향과 불확실성

> **먼저 한 문장:** 일부 관측으로 전체를 추정할 때 표본을 뽑는 방식과 추정의 불확실성을 함께 살핍니다.

모든 고객에게 물어볼 수 없어 일부를 조사해야 할 때가 많습니다. 조사한 사람의 구성과 우연한 차이를 이해해야 작은 조사 결과를 전체의 확실한 사실로 과장하지 않습니다.

## 먼저 알아둘 말


## 작은 예로 이해하기

급식 만족도를 알아보려고 친한 친구 10명만 물으면 학교 전체 의견과 다를 수 있습니다. 응답 수를 늘려도 같은 모임에서만 물으면 편향이 남습니다. 학년과 반이 다양하게 포함되도록 뽑고, 조사 결과가 실제 전체 값과 어느 정도 다를 수 있는지도 함께 봅니다.

## 익숙한 장면과 연결하기

국의 맛을 보려고 한 숟갈을 뜰 때 충분히 저었는지가 중요합니다. 위에 뜬 기름만 맛보면 숟갈을 크게 떠도 전체 맛을 대표하지 못합니다.

**비유의 한계 — 이 점은 달라요:** 표본 수가 커져도 선택 편향은 사라지지 않습니다. 신뢰구간의 의미는 사용한 추정 절차와 가정에 따르며 개인 한 명의 결과 범위를 뜻하지 않습니다.

## 읽기 전 길잡이

일부 관측으로 전체를 추정할 때 표본을 뽑는 방식과 추정의 불확실성을 함께 살핍니다. 아래 예제는 외부 시스템에 연결하지 않는 작은 학습용 사례입니다. 입력, 처리 조건, 결과를 순서대로 살펴보세요.

1. 추정 대상과 표본 추출 경로를 먼저 정의합니다.
2. 대표성·중복·응답 누락을 확인합니다.
3. 추정값과 불확실성을 함께 보고합니다.

## 예제로 확인하기

```python
import math
p, n = 0.5, 400
se = math.sqrt(p*(1-p)/n)
print(round(p-1.96*se, 3), round(p+1.96*se, 3))
assert round(se, 3) == 0.025
```

## 결과를 해석하기

독립적인 무작위 표본의 비율을 정규 근사하는 학습 예제입니다. 400건에서 비율 0.5의 표준오차는 0.025입니다. 실제 분석에서는 표본 설계와 근사 조건, 적절한 구간 추정법을 확인해야 합니다.

## 실무에 옮기기 전

표본 수가 커져도 선택 편향은 사라지지 않습니다. 신뢰구간의 의미는 사용한 추정 절차와 가정에 따르며 개인 한 명의 결과 범위를 뜻하지 않습니다. 실제 업무에서는 아이디어 탐색과 전체 고객 비율 추정은 요구 수준이 다릅니다. 불확실성을 작게 보이게 하려고 표본 수만 늘리기보다 누가 빠졌는지를 먼저 점검합니다.

## 확인 질문

예제에서 400건·비율 0.5의 표준오차는?

**답과 이유:** 제곱근 p 곱하기 1-p 나누기 n을 계산한 값입니다. 1.96은 근사 구간의 배수입니다.

## 1. 어떤 문제가 생겼나요?

가상 만족도 설문은 높지만 이탈 고객의 불만이 계속됩니다.

## 3. 원인 가설

활성 고객에게만 설문을 보내 생존자 편향이 생겼습니다.

## 4. 수정 방법

추정 대상을 분리하고 이탈 고객을 포함하는 표집 경로를 설계합니다.

## 5. 재검증

고객군별 응답 분포와 누락 사유를 기록하고 불확실성을 함께 제시합니다.

## 놓치기 쉬운 조건

표본 수가 커져도 선택 편향은 사라지지 않습니다. 신뢰구간의 의미는 사용한 추정 절차와 가정에 따르며 개인 한 명의 결과 범위를 뜻하지 않습니다.
