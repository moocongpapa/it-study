# AI·머신러닝·딥러닝의 차이

> **먼저 한 문장:** AI는 지능적 과제를 다루는 넓은 분야이고, 머신러닝은 데이터로 규칙을 학습하며 딥러닝은 여러 층의 신경망을 쓰는 방법입니다.

AI라는 이름이 붙었다고 모든 일을 스스로 이해하거나 해결하는 것은 아닙니다. 규칙·학습·신경망의 관계를 알면 설명을 구분해 듣고 업무에 필요한 방법을 고를 수 있습니다.

## 먼저 알아둘 말

```learning
{"slug":"ai-ml-dl","view":"words"}
```

## 작은 예로 이해하기

스팸 메일을 걸러 보겠습니다. 사람이 ‘제목에 무료가 있으면 스팸’이라고 정하면 직접 만든 규칙입니다. 정상 메일과 스팸 메일의 예시를 주고 판단 기준을 학습시키면 머신러닝입니다. 그 학습에 여러 층의 신경망을 쓰면 딥러닝입니다. 즉 딥러닝은 머신러닝의 한 종류이며, AI는 이보다 넓은 분야입니다. 단순한 자동문처럼 조건 하나를 실행한다고 모두 AI라고 부르지는 않습니다.

## 익숙한 장면과 연결하기

조리 업무에는 사람이 쓴 레시피와 경험으로 맛을 조절하는 방법이 있습니다. AI에도 명시적인 규칙과 자료를 통해 조정되는 방식이 함께 있습니다.

**비유의 한계 — 이 점은 달라요:** 모든 AI가 머신러닝은 아니며 모든 머신러닝이 거대한 신경망도 아닙니다. 사람처럼 이해한다는 비유로 정확성이나 자율성을 보장할 수 없습니다.

## 직접 확인하기

먼저 AI 안에 머신러닝, 그 안에 딥러닝이 들어가는 관계를 보세요. 아래 메일 사례에서는 판단 규칙을 사람이 직접 썼는지, 예시 자료로 모델을 조정했는지 구별합니다. ‘데이터로 학습’을 골랐다고 반드시 딥러닝인 것은 아닙니다.

```learning
{"slug":"ai-ml-dl","view":"explore"}
```

## 읽기 전 길잡이

AI는 지능적 과제를 다루는 넓은 분야이고, 머신러닝은 데이터로 규칙을 학습하며 딥러닝은 여러 층의 신경망을 쓰는 방법입니다. 아래 예제는 외부 시스템에 연결하지 않는 작은 학습용 사례입니다. 입력, 처리 조건, 결과를 순서대로 살펴보세요.

1. 해결할 과제와 성공 기준을 먼저 적습니다.
2. 규칙으로 충분한지 학습할 자료가 필요한지 판단합니다.
3. 새 자료에서 성능과 잘못된 결과의 영향을 확인합니다.

## 예제로 확인하기

```python
normal=[1,2,3]; unusual=[8,9,10]
threshold=(sum(normal)/len(normal)+sum(unusual)/len(unusual))/2
print("자료로 정한 경계:",threshold)
assert 7>threshold
```

## 결과를 해석하기

작은 예제는 두 집단의 평균으로 경계를 정한 단순 분류 규칙입니다. 이 계산이 사람의 이해를 구현하거나 새 상황의 정확성을 입증하는 것은 아닙니다. 업무에 맞는 독립 평가가 필요합니다.

## 실무에 옮기기 전

모든 AI가 머신러닝은 아니며 모든 머신러닝이 거대한 신경망도 아닙니다. 사람처럼 이해한다는 비유로 정확성이나 자율성을 보장할 수 없습니다. 실제 업무에서는 문제와 오류 비용을 기준으로 가장 단순한 기준선부터 비교합니다. 모델의 이름보다 실제 업무 품질과 유지 비용을 선택 근거로 삼습니다.
