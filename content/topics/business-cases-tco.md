# 사업 타당성·총비용·AI 업무 효과

> **먼저 한 문장:** IT·AI 도입의 타당성은 구매 가격만이 아니라 구현·운영·오류·사람의 작업을 포함한 총비용과 효과로 판단합니다.

도입 가격만 싸다고 전체 업무의 비용이 줄지는 않습니다. 준비·운영·검토·수정 시간을 함께 보면 IT와 AI가 실제로 어떤 효과와 부담을 만드는지 비교할 수 있습니다.

## 먼저 알아둘 말

```learning
{"slug":"business-cases-tco","view":"words"}
```

## 작은 예로 이해하기

월 사용료가 싼 AI 도구도 연결 개발과 답변 검토에 시간이 많이 들 수 있습니다. 가상의 비교에서 초안 작성 10분을 줄였지만 검토가 8분 늘었다면 순수 절감은 2분입니다. 사용료, 개발, 운영, 오류 수정과 사람의 시간을 같은 기간 기준으로 계산해야 합니다.

## 익숙한 장면과 연결하기

프린터 가격이 싸도 잉크와 수리, 관리 시간이 비싸면 총지출이 커집니다. AI 서비스도 API 요금뿐 아니라 데이터 정리, 검토, 평가, 장애 대응, 전환 비용을 함께 봐야 합니다.

**비유의 한계 — 이 점은 달라요:** 예상 절감 시간은 실제 현금 절감과 같지 않을 수 있습니다. 수요·단가·오류 비용은 변하며 이 예제의 숫자는 가상 계산으로 실제 가격이나 수익을 보장하지 않습니다.

## 직접 확인하기

도입 가격과 총비용과 순효과을 번갈아 선택하세요. 바로 아래 설명에서 무엇을 공유하고 무엇이 달라지는지 비교합니다. 버튼을 누르는 것보다 차이를 한 가지 말해 보는 것이 목표예요.

# 사업 타당성·총비용·AI 업무 효과 · 작동 원리

월 3000분을 아꼈다는 주장과 달리 검토·재작업을 빼면 순절감은 1700분입니다. 총비용 8400은 예제에 적은 비용만 포함하므로 실제 업무에서는 인력·데이터·보안·종료 비용을 추가해야 합니다. 시간과 비용은 단위가 달라 그대로 더하거나 빼지 않습니다.

## 읽기 전 길잡이

IT·AI 도입의 타당성은 구매 가격만이 아니라 구현·운영·오류·사람의 작업을 포함한 총비용과 효과로 판단합니다. 아래 예제는 외부 시스템에 연결하지 않는 작은 학습용 사례입니다. 입력, 처리 조건, 결과를 순서대로 살펴보세요.

1. 현재 방식의 시간·품질·비용과 도입 후 변화를 같은 기준으로 정합니다.
2. 초기·반복·오류·사람 검토·전환 비용을 기간과 함께 계산합니다.
3. 낙관·기준·비관 가정을 비교하고 실제 결과로 타당성을 갱신합니다.

## 예제로 확인하기

```python
volume = 1000  # 가상의 월 처리 건수
saved_minutes = volume * 3
review_minutes = volume * 0.8
rework_minutes = 100 * 5
net_minutes = saved_minutes - review_minutes - rework_minutes
monthly_cost = 200 + 300 + 100  # 가상 단위: API, 운영, 평가
setup_cost = 1200
tco_12_months = setup_cost + 12 * monthly_cost
assert net_minutes == 1700
assert tco_12_months == 8400
print(net_minutes, tco_12_months)
```

## 결과를 해석하기

월 3000분을 아꼈다는 주장과 달리 검토·재작업을 빼면 순절감은 1700분입니다. 총비용 8400은 예제에 적은 비용만 포함하므로 실제 업무에서는 인력·데이터·보안·종료 비용을 추가해야 합니다. 시간과 비용은 단위가 달라 그대로 더하거나 빼지 않습니다.

## 실무에 옮기기 전

예상 절감 시간은 실제 현금 절감과 같지 않을 수 있습니다. 수요·단가·오류 비용은 변하며 이 예제의 숫자는 가상 계산으로 실제 가격이나 수익을 보장하지 않습니다. 실제 업무에서는 가정이 많은 초기에는 단일 수익 숫자보다 범위와 손익을 바꾸는 조건을 보여 줍니다. 시간 절감이 실제 재배치나 처리량 개선으로 이어지는지 확인하고 품질·개인정보·운영 위험을 비용 숫자 하나로 지우지 않습니다.

**답과 이유:** 순효과에는 남은 사람 작업이 포함되며 시간과 금액은 단위를 구분해야 합니다.
