# LLM의 사전학습·후속 학습·추론

> **먼저 한 문장:** 언어 모델은 문맥에서 다음 토큰을 예측하도록 학습하며 후속 학습으로 지시 응답 등을 조정하고 추론 때 문맥을 바탕으로 출력을 만듭니다.

챗봇의 답이 자연스러우면 대화 중에 모든 사실을 새로 배우고 기억한다고 생각하기 쉽습니다. 학습과 추론을 구분하면 답변의 한계와 자료를 업데이트하는 방법을 이해할 수 있습니다.

## 먼저 알아둘 말

```learning
{"slug":"llm-pretraining","view":"words"}
```

## 작은 예로 이해하기

언어 모델이 문장을 이어 쓰는 과정을 생각해 보세요. 많은 글에서 다음 토큰을 예측하며 가중치를 조정하는 과정이 사전학습입니다. 이후 지시를 따르는 답변 예시 등으로 응답 방식을 더 조정할 수 있습니다. 우리가 질문할 때는 주어진 문맥으로 답을 생성하는 추론을 합니다. 보통 질문 한 번마다 모델의 가중치를 새로 학습시키는 것은 아닙니다.

## 익숙한 장면과 연결하기

많은 글을 읽고 다음에 올 말을 연습하는 사람을 떠올려 볼 수 있습니다. 다만 모델은 사실을 확인한 도서관 사서가 아니라 학습된 수치로 출력 분포를 계산합니다.

**비유의 한계 — 이 점은 달라요:** 다음 토큰 예측이 사실성·추론 능력·안전을 자동 보장하지 않습니다. 학습에 노출된 자료와 현재 지식도 구분해야 하며 추론 중 모든 대화가 자동으로 가중치를 바꾸는 것은 아닙니다.

## 직접 확인하기

사전학습 → 후속 학습 → 문맥으로 추론 순서로 읽어 보세요. 뒤의 과정에서 필요한 것이 앞에서 어떻게 준비되는지 찾습니다. 숫자는 읽는 순서이며 모든 상황이 정확히 세 단계라는 뜻은 아닙니다.

```learning
{"slug":"llm-pretraining","view":"explore"}
```

# LLM의 사전학습·후속 학습·추론 · 작동 원리

정답 토큰에 부여한 확률의 음의 로그를 계산한 작은 손실 예제입니다. 정답 확률이 커질수록 손실이 작아집니다. 전체 모델이나 학습 자료 수집·분산 학습을 구현한 코드는 아닙니다.

## 전체 흐름부터 보기

```learning
{"slug":"llm-pretraining","view":"trace"}
```

## 예제와 내부 동작

아래 자료를 읽을 때 **입력 → 바뀌는 값이나 상태 → 결과**를 찾아보세요. 모르는 말은 밑줄 표시를 눌러 뜻을 확인할 수 있어요.

<!-- classroom-reference:start -->
## 읽기 전 길잡이

언어 모델은 문맥에서 다음 토큰을 예측하도록 학습하며 후속 학습으로 지시 응답 등을 조정하고 추론 때 문맥을 바탕으로 출력을 만듭니다. 아래 예제는 외부 시스템에 연결하지 않는 작은 학습용 사례입니다. 입력, 처리 조건, 결과를 순서대로 살펴보세요.

1. 자료에서 토큰과 문맥 예측 목표를 만듭니다.
2. 사전학습과 지시·선호 등의 후속 학습으로 파라미터를 조정합니다.
3. 추론에서는 주어진 문맥과 생성 설정으로 출력을 만듭니다.

## 예제로 확인하기

```python
import math
probabilities=[0.1,0.7,0.2]
target_index=1
loss=-math.log(probabilities[target_index])
assert 0<loss<1
print(round(loss,3))
```

## 결과를 해석하기

정답 토큰에 부여한 확률의 음의 로그를 계산한 작은 손실 예제입니다. 정답 확률이 커질수록 손실이 작아집니다. 전체 모델이나 학습 자료 수집·분산 학습을 구현한 코드는 아닙니다.

## 실무에 옮기기 전

다음 토큰 예측이 사실성·추론 능력·안전을 자동 보장하지 않습니다. 학습에 노출된 자료와 현재 지식도 구분해야 하며 추론 중 모든 대화가 자동으로 가중치를 바꾸는 것은 아닙니다. 실제 업무에서는 문제의 원인이 최신 지식 부족인지 출력 방식인지 구분합니다. 지식 갱신과 행동 적응을 같은 방법 하나로 해결하려 하지 않고 독립 평가로 효과를 확인합니다.

## 확인 질문

정답 토큰 확률이 높아지면 예제 손실은?

**답과 이유:** 음의 로그 손실은 정답에 높은 확률을 줄수록 작아집니다.
