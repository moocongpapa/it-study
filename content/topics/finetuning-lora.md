# 미세조정·LoRA·데이터셋 설계

> **먼저 한 문장:** 미세조정은 원하는 입력·출력 패턴으로 모델을 적응시키며 LoRA는 일부 가중치 변화량을 작은 행렬로 표현합니다.

AI가 원하는 말투나 출력 방식을 반복해서 잘 따르도록 적응시키고 싶을 때가 있습니다. 미세조정의 역할을 알면 자료 검색만으로 해결할 문제와 학습이 필요한 문제를 구분할 수 있습니다.

## 먼저 알아둘 말

```learning
{"slug":"finetuning-lora","view":"words"}
```

## 작은 예로 이해하기

상담 답변을 늘 ‘요약 → 해결 순서 → 확인 질문’ 형식으로 쓰게 하려면 좋은 입력·답변 예시를 모아 모델을 조정할 수 있습니다. LoRA는 전체 가중치를 모두 바꾸는 대신 작은 추가 행렬로 변화량을 표현하는 방식입니다. 매일 바뀌는 영업시간을 알려주는 문제라면 최신 자료를 검색하는 방법도 비교해야 합니다.

## 익숙한 장면과 연결하기

새 업무를 가르칠 때 조직 전체 매뉴얼을 모두 다시 쓰는 대신 특정 업무의 보충 지침을 만드는 모습과 비슷합니다. 작은 수정도 기존 업무에 영향을 줄 수 있습니다.

**비유의 한계 — 이 점은 달라요:** LoRA가 모든 학습·서빙 메모리를 없애지는 않습니다. 좋은 데이터와 평가가 필요하며 최신 지식 저장이나 사실성 문제를 자동 해결하지 않습니다.

## 직접 확인하기

검색으로 근거 제공과 미세조정·LoRA을 번갈아 선택하세요. 바로 아래 설명에서 무엇을 공유하고 무엇이 달라지는지 비교합니다. 버튼을 누르는 것보다 차이를 한 가지 말해 보는 것이 목표예요.

```learning

```

# 미세조정·LoRA·데이터셋 설계 · 작동 원리

2×1과 1×2 행렬의 곱으로 2×2 변화량을 만듭니다. 실제 LoRA의 스케일·적용 층·학습 루프는 생략했습니다. 랭크가 낮으면 학습 대상은 줄지만 표현 가능한 변화도 제한됩니다.

## 예제와 내부 동작

아래 자료를 읽을 때 **입력 → 바뀌는 값이나 상태 → 결과**를 찾아보세요. 모르는 말은 밑줄 표시를 눌러 뜻을 확인할 수 있어요.

## 읽기 전 길잡이

미세조정은 원하는 입력·출력 패턴으로 모델을 적응시키며 LoRA는 일부 가중치 변화량을 작은 행렬로 표현합니다. 아래 예제는 외부 시스템에 연결하지 않는 작은 학습용 사례입니다. 입력, 처리 조건, 결과를 순서대로 살펴보세요.

1. 원하는 행동과 일관된 학습·검증 예제를 준비합니다.
2. 전체 가중치 또는 저랭크 변화량의 학습 범위를 정합니다.
3. 목표 과제와 기존 능력·안전·비용을 비교합니다.

## 예제로 확인하기

```python
b=[[1],[2]]; a=[[3,4]]
delta=[[b[i][0]*a[0][j] for j in range(2)] for i in range(2)]
assert delta==[[3,4],[6,8]]
print(delta)
```

## 결과를 해석하기

2×1과 1×2 행렬의 곱으로 2×2 변화량을 만듭니다. 실제 LoRA의 스케일·적용 층·학습 루프는 생략했습니다. 랭크가 낮으면 학습 대상은 줄지만 표현 가능한 변화도 제한됩니다.

## 실무에 옮기기 전

LoRA가 모든 학습·서빙 메모리를 없애지는 않습니다. 좋은 데이터와 평가가 필요하며 최신 지식 저장이나 사실성 문제를 자동 해결하지 않습니다. 실제 업무에서는 먼저 프롬프트·검색으로 해결 가능한지 평가합니다. 반복적인 행동·형식 오류가 남고 좋은 학습 예제가 확보될 때 미세조정을 검토합니다.
