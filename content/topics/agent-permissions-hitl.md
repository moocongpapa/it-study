## 읽기 전 길잡이

AI가 행동을 제안하는 범위와 실제 실행 권한을 나누고 중요한 변경은 대상·내용이 명확한 사람 승인과 연결합니다. 아래 예제는 외부 시스템에 연결하지 않는 작은 학습용 사례입니다. 입력, 처리 조건, 결과를 순서대로 살펴보세요.

1. 도구와 자원별 최소 권한을 정의합니다.
2. 실행할 대상·내용·영향을 검토 가능한 초안으로 만듭니다.
3. 승인을 해당 작업에 묶고 실행·결과를 감사 기록으로 남깁니다.

## 예제로 확인하기

```python
proposal={"action":"update","resource":"ticket-7","version":3}
approval={"resource":"ticket-7","version":3,"approved":True}
assert approval["approved"] and approval["resource"]==proposal["resource"] and approval["version"]==proposal["version"]
print("작업 일치 검사 예시")
```

## 결과를 해석하기

대상과 버전이 같은지 확인하는 모형입니다. 실제 승인은 신뢰할 수 있는 인증 채널에서 얻고 작업 내용 해시·만료·승인자 권한을 서버에서 검증해야 합니다. 모델 출력으로 approval을 만들면 안 됩니다.

## 실무에 옮기기 전

승인 버튼 하나가 모든 미래 행동을 허용하는 것은 아닙니다. 승인 내용이 바뀌거나 만료되면 다시 검증하며 모델이 쓴 승인 문자열은 신뢰할 근거가 아닙니다. 실제 업무에서는 되돌리기 어려움과 외부 영향, 민감도에 따라 승인 수준을 정합니다. 반복 승인으로 검토가 형식화되지 않도록 초안·차이·실행 결과를 명확히 보여 줍니다.
