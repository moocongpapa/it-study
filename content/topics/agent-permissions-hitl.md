# 에이전트 권한·사람 승인·감사

> **먼저 한 문장:** AI가 행동을 제안하는 범위와 실제 실행 권한을 나누고 중요한 변경은 대상·내용이 명확한 사람 승인과 연결합니다.

답을 생성하는 AI에 메일 전송이나 데이터 변경 권한까지 주면 오류의 영향이 커집니다. 도구 권한과 사람 승인 기준을 정해야 편리함과 통제를 함께 유지할 수 있습니다.

## 먼저 알아둘 말

```learning

```

## 작은 예로 이해하기

AI가 회의 초청장을 작성하는 것과 참석자들에게 실제 발송하는 것은 영향이 다릅니다. 발송 전에는 받는 사람과 정확한 내용을 보여주고 승인을 연결합니다. ‘알아서 해’라는 오래된 말 대신 어떤 행동을 승인했는지 남겨야 나중에 확인할 수 있습니다.

## 익숙한 장면과 연결하기

신입 직원이 결재 초안을 만들 수 있어도 모든 지출 권한을 받는 것은 아닙니다. 승인된 금액과 대상, 유효한 시점이 정해져야 합니다.

**비유의 한계 — 이 점은 달라요:** 승인 버튼 하나가 모든 미래 행동을 허용하는 것은 아닙니다. 승인 내용이 바뀌거나 만료되면 다시 검증하며 모델이 쓴 승인 문자열은 신뢰할 근거가 아닙니다.

## 직접 확인하기

사례가 낮은 영향의 조회과 승인이 필요한 실행 중 어디에 해당하는지 골라 보세요. 고른 뒤 나오는 이유를 읽고, 같은 기준으로 다음 사례를 판단합니다.
