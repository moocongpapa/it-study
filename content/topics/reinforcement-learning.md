# 강화학습·보상·정책

> **먼저 한 문장:** 강화학습은 행동이 다음 상태와 보상에 미치는 영향을 이용해 장기적인 행동 전략을 학습합니다.

정답이 적힌 자료만으로 배우기 어려운 문제도 있습니다. 행동 뒤에 얻는 보상을 통해 배우는 방식을 알면 게임·제어·업무 자동화의 적합성과 위험을 함께 생각할 수 있습니다.

## 먼저 알아둘 말

```learning
{"slug":"reinforcement-learning","view":"words"}
```

## 작은 예로 이해하기

미로를 걷는 가상의 로봇이 목표에 도달하면 보상을 받습니다. 당장 가까워 보이는 길이 막다른 길일 수 있으므로 나중 보상까지 고려해 행동 규칙인 정책을 학습합니다. 보상을 ‘이동 횟수’에 잘못 주면 목표에 가기보다 계속 돌아다니는 행동을 배울 수도 있습니다.

## 익숙한 장면과 연결하기

게임에서 바로 얻는 점수뿐 아니라 다음 수의 기회를 생각하는 것과 비슷합니다. 점수를 주는 방식이 잘못되면 원하는 플레이와 다른 행동을 익힐 수 있습니다.

**비유의 한계 — 이 점은 달라요:** 좋은 보상 점수가 안전하고 원하는 행동을 보장하지 않습니다. 실제 환경의 탐색은 비용과 위험이 있으며 오프라인 자료로 모든 행동 결과를 알 수 없습니다.

## 직접 확인하기

## 읽기 전 길잡이

강화학습은 행동이 다음 상태와 보상에 미치는 영향을 이용해 장기적인 행동 전략을 학습합니다. 아래 예제는 외부 시스템에 연결하지 않는 작은 학습용 사례입니다. 입력, 처리 조건, 결과를 순서대로 살펴보세요.

1. 상태·행동·보상과 종료 조건을 정의합니다.
2. 행동의 결과를 관측하며 가치나 정책을 갱신합니다.
3. 장기 성과와 안전 제약을 별도로 검증합니다.

## 예제로 확인하기

```python
q,reward,next_value=0.,1.,2.
learning_rate,gamma=0.1,0.9
q+=learning_rate*(reward+gamma*next_value-q)
assert abs(q-0.28)<1e-9
print(q)
```

## 결과를 해석하기

한 번의 Q 값 갱신을 보여 줍니다. 즉시 보상 1과 할인된 다음 가치 1.8을 합한 목표 2.8 쪽으로 10% 이동합니다. 완전한 환경·탐색·학습 루프는 생략했습니다.

## 실무에 옮기기 전

좋은 보상 점수가 안전하고 원하는 행동을 보장하지 않습니다. 실제 환경의 탐색은 비용과 위험이 있으며 오프라인 자료로 모든 행동 결과를 알 수 없습니다. 실제 업무에서는 탐색을 허용할 범위와 금지 행동을 먼저 정합니다. 보상 최적화와 실제 원하는 결과를 구분하고 안전 기준을 별도 통과 조건으로 둡니다.
