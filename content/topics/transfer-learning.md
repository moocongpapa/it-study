# 전이 학습·동결·미세조정

> **먼저 한 문장:** 이미 학습한 표현을 새 과제에 활용하되 무엇을 고정하고 바꿀지와 자료 적합성을 선택합니다.

새로운 업무마다 큰 모델을 처음부터 학습하기는 어렵습니다. 이미 배운 표현을 활용하는 방법을 알면 필요한 자료와 학습 비용을 줄일 수 있는지 판단할 수 있습니다.

## 먼저 알아둘 말

```learning
{"slug":"transfer-learning","view":"words"}
```

## 작은 예로 이해하기

많은 사진으로 학습한 모델을 꽃 종류 분류에 활용한다고 합시다. 이미 익힌 특징 일부를 고정하고 마지막 분류 부분부터 학습할 수 있습니다. 필요하면 더 많은 부분을 조정합니다. 기존 사진과 새 사진의 성격이 다르면 그대로 가져오는 것만으로 좋은 성능이 나지는 않습니다.

## 익숙한 장면과 연결하기

기본 운전 기술을 익힌 사람이 다른 차의 조작을 배우는 것과 비슷합니다. 공통 기술을 활용할 수 있지만 새 환경의 차이를 따로 확인해야 합니다.

**비유의 한계 — 이 점은 달라요:** 사전학습 모델의 성능이 모든 분야에 그대로 이전되지는 않습니다. 라이선스·자료 차이·평가 누출과 편향을 함께 확인해야 합니다.

## 직접 확인하기

학습 대상 크기를 세는 구조 예제입니다. 인코더를 고정하고 출력 헤드 20개만 갱신한다고 가정합니다. 실제 프레임워크에서는 미분·옵티마이저·평가 모드 설정도 맞춰야 합니다.

## 전체 흐름부터 보기

```learning

```

## 예제와 내부 동작

아래 자료를 읽을 때 **입력 → 바뀌는 값이나 상태 → 결과**를 찾아보세요. 모르는 말은 밑줄 표시를 눌러 뜻을 확인할 수 있어요.

<!-- classroom-reference:start -->
## 읽기 전 길잡이

이미 학습한 표현을 새 과제에 활용하되 무엇을 고정하고 바꿀지와 자료 적합성을 선택합니다. 아래 예제는 외부 시스템에 연결하지 않는 작은 학습용 사례입니다. 입력, 처리 조건, 결과를 순서대로 살펴보세요.

1. 사전학습 모델의 입력과 새 과제의 차이를 확인합니다.
2. 고정할 층과 학습할 부분·학습률을 정합니다.
3. 원래 능력 손실과 새 과제 성능을 함께 평가합니다.

## 예제로 확인하기

```python
parameters={"encoder":1000,"head":20}
trainable={"encoder":False,"head":True}
count=sum(n for name,n in parameters.items() if trainable[name])
assert count==20
print("학습 대상 수:",count)
```

## 결과를 해석하기

학습 대상 크기를 세는 구조 예제입니다. 인코더를 고정하고 출력 헤드 20개만 갱신한다고 가정합니다. 실제 프레임워크에서는 미분·옵티마이저·평가 모드 설정도 맞춰야 합니다.

## 실무에 옮기기 전

사전학습 모델의 성능이 모든 분야에 그대로 이전되지는 않습니다. 라이선스·자료 차이·평가 누출과 편향을 함께 확인해야 합니다. 실제 업무에서는 사용 가능한 자료량과 계산 예산, 보존해야 할 능력을 기준으로 변경 범위를 정합니다. 품질 향상뿐 아니라 배포·되돌리기와 라이선스 조건도 확인합니다.
