# GPU·정밀도·양자화·KV 캐시

> **먼저 한 문장:** AI 추론의 메모리와 속도는 가중치뿐 아니라 활성값·KV 캐시·배치·입출력과 정밀도의 영향을 받습니다.

AI 모델이 커지면 답변이 느려지거나 장비 메모리가 부족할 수 있습니다. GPU 추론의 병목을 이해하면 무작정 장비를 늘리기 전에 어떤 자원이 부족한지 확인할 수 있습니다.

## 먼저 알아둘 말

```learning
{"slug":"gpu-inference-optimization","view":"words"}
```

## 작은 예로 이해하기

모델 가중치가 GPU 메모리에 들어간다고 긴 대화 여러 개를 동시에 처리할 수 있는 것은 아닙니다. 계산 중간값과 앞서 처리한 토큰 정보를 담는 KV 캐시에도 공간이 필요합니다. 숫자를 더 적은 비트로 표현하는 양자화는 메모리를 줄일 수 있지만 품질과 실제 속도는 작업별로 확인해야 합니다.

## 익숙한 장면과 연결하기

공장의 기계 크기뿐 아니라 대기 중인 부품과 작업 중간 재료가 공간을 차지하는 것과 같습니다. 동시에 처리할 주문이 늘면 중간 저장 공간도 커집니다.

**비유의 한계 — 이 점은 달라요:** 낮은 비트 수가 메모리와 지연을 같은 비율로 줄이지는 않습니다. 커널 지원·메모리 대역폭·역양자화·품질 영향을 실제 장치에서 측정해야 합니다.

## 직접 확인하기

들어오는 양과 처리하는 양을 다르게 설정한 뒤 한 차례 진행하세요. 처리하지 못한 요청이 대기열에 남는지 확인합니다. 실제 시스템의 시간을 예측하는 측정 도구는 아닙니다.
