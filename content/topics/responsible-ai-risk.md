# 책임 있는 AI·위험 평가·모델 카드

> **먼저 한 문장:** AI 위험은 모델 점수만이 아니라 사용 맥락·영향받는 사람·오류 피해·책임과 통제를 함께 평가합니다.

평균 점수가 좋아도 특정 집단이나 드문 상황에 피해가 집중될 수 있습니다. 업무의 영향과 실패 비용을 먼저 살피면 평가·검토·이의 제기 절차를 필요한 수준으로 설계할 수 있습니다.

## 먼저 알아둘 말

```learning
{"slug":"responsible-ai-risk","view":"words"}
```

## 작은 예로 이해하기

글의 맞춤법을 제안하는 AI와 사람의 기회를 좌우하는 판단에 쓰는 AI는 같은 오류율이어도 피해가 다릅니다. 사용 목적, 영향을 받는 사람, 사람이 검토할 방법, 이의를 제기할 경로를 함께 살핍니다. 모델 카드는 이런 사용 범위와 한계, 평가 결과를 기록해 판단을 돕는 문서입니다.

## 익숙한 장면과 연결하기

자동문을 만들 때 잘 열리는 비율뿐 아니라 누가 끼일 수 있는지, 고장 때 어떻게 멈추는지와 누가 관리하는지도 보는 것과 같습니다.

**비유의 한계 — 이 점은 달라요:** 한 번의 점검이나 모델 카드가 모든 안전·공정성·준수를 보증하지 않습니다. 사용 범위와 환경이 바뀌면 위험과 평가도 다시 검토해야 합니다.

## 직접 확인하기

전체 평균과 상황과 집단별 확인을 번갈아 선택하세요. 바로 아래 설명에서 무엇을 공유하고 무엇이 달라지는지 비교합니다. 버튼을 누르는 것보다 차이를 한 가지 말해 보는 것이 목표예요.

```learning
{"slug":"responsible-ai-risk","view":"explore"}
```

```learning

```
