# 분류·정밀도·재현율과 임계값

> **먼저 한 문장:** 분류의 품질은 맞힌 비율뿐 아니라 오탐과 놓침을 나누고 실제 비용에 맞는 임계값으로 판단합니다.

불량이나 사기처럼 드문 일을 찾을 때는 전체 정답률이 높아도 중요한 사례를 놓칠 수 있습니다. 무엇을 놓치고 무엇을 잘못 경고했는지 나눠 봐야 실제 업무 품질을 판단할 수 있습니다.

## 먼저 알아둘 말

```learning
{"slug":"classification-metrics","view":"words"}
```

## 작은 예로 이해하기

스팸이라고 표시한 메일 10개 중 진짜 스팸이 8개라면 정밀도는 8/10입니다. 전체 진짜 스팸이 20개였고 그중 8개를 찾았다면 재현율은 8/20입니다. 스팸 판정 기준을 느슨하게 하면 더 많이 잡을 수 있지만 정상 메일까지 막을 수 있어요. 두 비율은 서로 다른 질문에 답합니다.

## 익숙한 장면과 연결하기

수하물 검사에서 위험 물건을 놓치는 것과 안전한 가방을 재검사하는 것은 서로 다른 비용입니다. 둘 다 맞고 틀림이라는 한 숫자로만 볼 수 없습니다.

**비유의 한계 — 이 점은 달라요:** 모델 점수가 항상 잘 보정된 확률은 아닙니다. 희귀 사건에서는 정확도가 높아도 관심 사건을 놓칠 수 있고, 지표는 선택한 임계값에 따라 달라집니다.

## 직접 확인하기

판정 기준을 움직이며 맞게 찾은 것, 잘못 표시한 것, 놓친 것의 수를 비교하세요. 정밀도와 재현율이 답하는 질문은 서로 다릅니다.

```learning
{"slug":"classification-metrics","view":"explore"}
```

```learning
{"slug":"classification-metrics","view":"recall"}
```

## 읽기 전 길잡이

분류의 품질은 맞힌 비율뿐 아니라 오탐과 놓침을 나누고 실제 비용에 맞는 임계값으로 판단합니다. 아래 예제는 외부 시스템에 연결하지 않는 작은 학습용 사례입니다. 입력, 처리 조건, 결과를 순서대로 살펴보세요.

1. 양성·음성과 오탐·놓침의 의미를 업무에 맞춰 정합니다.
2. 혼동표로 정밀도와 재현율을 계산합니다.
3. 검증 자료에서 임계값을 선택하고 새 자료에서 확인합니다.

## 예제로 확인하기

```python
tp,fp,fn=8,2,4
precision=tp/(tp+fp); recall=tp/(tp+fn)
assert precision==0.8
print(round(precision,2),round(recall,2))
```

## 결과를 해석하기

예측 양성 10건 중 8건이 맞아 정밀도는 0.8이고 실제 양성 12건 중 8건을 찾아 재현율은 약 0.67입니다. 분모가 다르므로 서로 바꾸어 쓸 수 없습니다.

## 실무에 옮기기 전

모델 점수가 항상 잘 보정된 확률은 아닙니다. 희귀 사건에서는 정확도가 높아도 관심 사건을 놓칠 수 있고, 지표는 선택한 임계값에 따라 달라집니다. 실제 업무에서는 검증 자료로 업무 비용과 처리 용량에 맞는 경계를 고릅니다. 테스트에서 경계를 반복 조정하지 않고 배포 후 발생률 변화도 관측합니다.

## 확인 질문

예제 정밀도는 얼마인가요?

**답과 이유:** 참 양성 8을 예측 양성 10으로 나누면 0.8입니다.

# 분류·정밀도·재현율과 임계값 · 실무 선택

## 읽기 전 길잡이

같은 개념도 업무의 규모, 오류 비용, 운영 역량에 따라 적용 방식이 달라집니다. 아래 비교는 특정 제품의 성능 순위가 아닌 선택 기준입니다.

| 선택 | 얻는 점 | 감수할 점 |
|---|---|---|
| 높은 임계값 | 검토 대상 수를 줄일 수 있음 | 놓침이 늘 수 있음 |
| 낮은 임계값 | 더 많은 양성을 찾을 수 있음 | 오탐·처리량 부담 |

## 선택 기준

## 도입과 운영에서 확인할 것
