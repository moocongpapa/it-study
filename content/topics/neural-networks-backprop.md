# 신경망·활성화 함수·역전파

> **먼저 한 문장:** 신경망은 선형 연산과 비선형 함수를 층으로 쌓고 역전파로 각 파라미터의 기울기를 계산합니다.

신경망이 학습한다는 말만 들으면 무엇이 달라지는지 막연합니다. 입력이 결과로 바뀌고 오류가 거꾸로 전달되는 흐름을 알면 내부의 수치가 조정되는 과정을 설명할 수 있습니다.

## 먼저 알아둘 말

```learning
{"slug":"neural-networks-backprop","view":"words"}
```

## 작은 예로 이해하기

두 입력에 각각 가중치를 곱해 더하고, 비선형 함수를 통과시켜 예측값을 만든다고 해 봅시다. 예측이 틀렸을 때 역전파는 그 오차에 각 가중치가 어떻게 영향을 줬는지 기울기를 계산합니다. 그 기울기로 가중치를 조금 고칩니다. 실제 뇌를 그대로 복제한 장치라는 뜻은 아닙니다.

## 익숙한 장면과 연결하기

여러 작업대가 재료를 조금씩 가공하는 공장을 떠올려 보세요. 최종 품질 오차를 어느 작업대가 얼마나 바꿀 수 있는지 거꾸로 계산하는 과정이 필요합니다.

**비유의 한계 — 이 점은 달라요:** 뉴런이라는 이름이 실제 뇌의 동작을 그대로 재현한다는 뜻은 아닙니다. 역전파는 기울기 계산 절차이며 파라미터 갱신은 옵티마이저가 수행합니다.

## 읽기 전 길잡이

신경망은 선형 연산과 비선형 함수를 층으로 쌓고 역전파로 각 파라미터의 기울기를 계산합니다. 아래 예제는 외부 시스템에 연결하지 않는 작은 학습용 사례입니다. 입력, 처리 조건, 결과를 순서대로 살펴보세요.

## 예제로 확인하기

```python
x,w,y=2.,1.,5.
pred=w*x
loss=(pred-y)**2
grad=2*(pred-y)*x
assert loss==9 and grad==-12
print(loss,grad)
```
