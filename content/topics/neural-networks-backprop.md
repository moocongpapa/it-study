## 읽기 전 길잡이

신경망은 선형 연산과 비선형 함수를 층으로 쌓고 역전파로 각 파라미터의 기울기를 계산합니다. 아래 예제는 외부 시스템에 연결하지 않는 작은 학습용 사례입니다. 입력, 처리 조건, 결과를 순서대로 살펴보세요.

1. 층별 가중치와 활성화로 출력을 계산합니다.
2. 출력과 목표의 차이를 손실로 만듭니다.
3. 연쇄 법칙으로 기울기를 구하고 가중치를 갱신합니다.

## 예제로 확인하기

```python
x,w,y=2.,1.,5.
pred=w*x
loss=(pred-y)**2
grad=2*(pred-y)*x
assert loss==9 and grad==-12
print(loss,grad)
```

## 결과를 해석하기

가중치 하나인 선형 층의 미분 예제입니다. 출력 2, 정답 5이면 손실 9, w에 대한 기울기는 -12입니다. 여러 층에서는 각 연산의 미분을 연결합니다.

## 실무에 옮기기 전

뉴런이라는 이름이 실제 뇌의 동작을 그대로 재현한다는 뜻은 아닙니다. 역전파는 기울기 계산 절차이며 파라미터 갱신은 옵티마이저가 수행합니다. 실제 업무에서는 층을 늘리기 전에 자료와 평가가 타당한지 확인합니다. 기울기와 활성값을 관측해 학습 실패를 진단하고 더 깊은 구조의 이득을 검증합니다.

## 확인 질문

예제의 w에 대한 기울기는?

**답과 이유:** 2(pred-y)에 입력 x를 곱해 -12가 됩니다.
