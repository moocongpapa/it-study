# 컴퓨터 비전·합성곱·이미지 전처리

> **먼저 한 문장:** 이미지는 공간 구조를 가진 숫자 배열이며 합성곱은 같은 작은 필터를 여러 위치에 적용해 특징을 추출합니다.

사진 속 물체가 조금 옮겨져도 비슷한 특징을 알아보는 방법이 필요합니다. 작은 영역에서 특징을 찾는 흐름을 알면 이미지 모델이 보는 정보와 놓칠 수 있는 조건을 이해할 수 있습니다.

## 먼저 알아둘 말

```learning
{"slug":"convolution-vision","view":"words"}
```

## 작은 예로 이해하기

사진의 작은 3×3 영역을 보며 밝기가 갑자기 바뀌는 경계를 찾는다고 생각해 보세요. 같은 작은 필터를 사진 여러 위치에 움직이며 적용하는 연산이 합성곱입니다. 학습에서는 유용한 필터의 값을 조정합니다. 사진 크기나 색상 순서를 운영 때 다르게 처리하면 학습 때와 다른 입력이 됩니다.

## 익숙한 장면과 연결하기

돋보기로 종이의 작은 부분을 같은 방식으로 훑는 모습과 비슷합니다. 위치마다 다른 도구를 새로 만드는 대신 같은 검사 규칙을 반복합니다.

**비유의 한계 — 이 점은 달라요:** 작은 필터 예제는 완전한 시각 이해가 아닙니다. 해상도·색 채널·촬영 환경·변형에 따라 성능이 달라지고 데이터 분할의 중복도 주의해야 합니다.

## 직접 확인하기

작은 영역 → 특징 지도 → 모아서 판단 순서로 읽어 보세요. 뒤의 과정에서 필요한 것이 앞에서 어떻게 준비되는지 찾습니다. 숫자는 읽는 순서이며 모든 상황이 정확히 세 단계라는 뜻은 아닙니다.

```learning
{"slug":"convolution-vision","view":"explore"}
```

```learning

```

## 예제와 내부 동작

<!-- classroom-reference:start -->
## 읽기 전 길잡이

이미지는 공간 구조를 가진 숫자 배열이며 합성곱은 같은 작은 필터를 여러 위치에 적용해 특징을 추출합니다. 아래 예제는 외부 시스템에 연결하지 않는 작은 학습용 사례입니다. 입력, 처리 조건, 결과를 순서대로 살펴보세요.

1. 픽셀 범위·해상도·채널 순서를 맞춥니다.
2. 지역 필터와 계층적 표현으로 특징을 추출합니다.
3. 새 촬영 환경과 객체별로 예측 품질을 평가합니다.

## 예제로 확인하기

```python
patch=[[1,2],[3,4]]; kernel=[[1,0],[0,-1]]
value=sum(patch[i][j]*kernel[i][j] for i in range(2) for j in range(2))
assert value==-3
print(value)
```

## 결과를 해석하기

필터를 뒤집지 않는 작은 교차상관 계산으로, 딥러닝 라이브러리의 합성곱 구현 원리를 단순화합니다. 전체 이미지는 여러 위치와 채널, 배치 축까지 고려해야 합니다.

## 실무에 옮기기 전

작은 필터 예제는 완전한 시각 이해가 아닙니다. 해상도·색 채널·촬영 환경·변형에 따라 성능이 달라지고 데이터 분할의 중복도 주의해야 합니다. 실제 업무에서는 실제 카메라와 장치 조건에서 지연·전력·객체별 오류를 비교합니다. 증강은 정답 의미를 보존해야 하며 글자나 좌우 의미를 바꾸는 변형은 별도로 판단합니다.
