# 학습 루프·미니배치·평가 모드

> **먼저 한 문장:** 학습은 배치마다 예측·손실·기울기·갱신을 반복하며 평가 단계와 모델 상태를 구분합니다.

자료를 한 번 보여 주는 것만으로 원하는 모델이 완성되지는 않습니다. 나눠서 반복 학습하고 중간에 평가하는 과정을 알면 학습 중단과 자원 사용의 의미를 이해할 수 있습니다.

## 먼저 알아둘 말

```learning
{"slug":"training-loops-batching","view":"words"}
```

## 작은 예로 이해하기

학습 사진이 1,000장이라면 100장씩 묶어 예측·오차 계산·가중치 갱신을 반복할 수 있습니다. 묶음이 미니배치이고 전체 자료를 한 번 도는 것이 한 에포크입니다. 평가할 때는 가중치를 학습시키지 않으며, 드롭아웃처럼 학습과 평가에서 동작이 달라지는 층도 평가 모드로 바꿉니다.

## 익숙한 장면과 연결하기

많은 시험 답안을 몇 장씩 묶어 검토하는 과정과 비슷합니다. 연습하며 기준을 바꾸는 시간과 최종 채점 시간은 구분해야 합니다.

**비유의 한계 — 이 점은 달라요:** 미니배치 크기는 단순히 클수록 좋은 값이 아닙니다. 장치 메모리·일반화·학습률과 관계가 있고 평가 모드와 미분 비활성화도 서로 다른 개념입니다.

## 직접 확인하기

배치 묶음 → 학습·갱신 → 평가·반복 순서로 읽어 보세요. 뒤의 과정에서 필요한 것이 앞에서 어떻게 준비되는지 찾습니다. 숫자는 읽는 순서이며 모든 상황이 정확히 세 단계라는 뜻은 아닙니다.

## 읽기 전 길잡이

```python

print(batches)
```
