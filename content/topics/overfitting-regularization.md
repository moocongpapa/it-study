# 과적합·일반화·정규화

> **먼저 한 문장:** 학습 자료에만 잘 맞는 모델을 피하려면 새 자료 성능과 모델 복잡도·규제를 함께 조절합니다.

연습 문제는 잘 풀지만 처음 보는 문제에는 약한 모델이 생길 수 있습니다. 과적합을 알면 학습 점수만 높이는 대신 새 자료에서도 통하는지를 확인하게 됩니다.

## 먼저 알아둘 말

```learning
{"slug":"overfitting-regularization","view":"words"}
```

## 작은 예로 이해하기

연습 문제 10개의 답을 외운 학생은 그 10개에서는 만점이지만 숫자만 바뀌어도 틀릴 수 있습니다. 모델이 학습 자료의 우연한 특징까지 외운 상태가 과적합입니다. 새 자료에서도 잘 맞는지가 일반화 성능입니다. 모델을 지나치게 복잡하게 만들지 않거나 가중치에 제약을 주는 방법은 이런 위험을 줄이는 데 쓰입니다.

## 익숙한 장면과 연결하기

시험지 답을 통째로 외우면 연습 점수는 높지만 새로운 문제에 약해집니다. 핵심 원리를 익혔는지는 다른 문제로 확인해야 합니다.

**비유의 한계 — 이 점은 달라요:** 학습·검증 차이가 모두 과적합 때문인 것은 아닙니다. 분할 오류·분포 변화·자료 부족도 확인해야 하며 규제를 세게 한다고 항상 좋아지지 않습니다.

## 직접 확인하기

연습 자료의 점수과 새 자료의 점수을 번갈아 선택하세요. 바로 아래 설명에서 무엇을 공유하고 무엇이 달라지는지 비교합니다. 버튼을 누르는 것보다 차이를 한 가지 말해 보는 것이 목표예요.

## 읽기 전 길잡이

학습 자료에만 잘 맞는 모델을 피하려면 새 자료 성능과 모델 복잡도·규제를 함께 조절합니다. 아래 예제는 외부 시스템에 연결하지 않는 작은 학습용 사례입니다. 입력, 처리 조건, 결과를 순서대로 살펴보세요.

1. 학습과 검증 오차가 어떻게 달라지는지 봅니다.
2. 모델 용량·정규화·조기 종료를 조정합니다.
3. 독립 자료로 일반화와 구간별 실패를 확인합니다.

## 예제로 확인하기

```python
weights=[3.,4.]; data_loss=2.; lam=0.1
penalty=lam*sum(w*w for w in weights)
assert penalty==2.5
print("규제 포함 목적함수:",data_loss+penalty)
```

## 결과를 해석하기

L2 규제 항은 가중치 제곱합 25에 0.1을 곱한 2.5입니다. 실제 학습은 자료 손실과 이 항의 합을 최적화합니다. 이 계산만으로 일반화 개선을 보장하지 않습니다.

## 실무에 옮기기 전

학습·검증 차이가 모두 과적합 때문인 것은 아닙니다. 분할 오류·분포 변화·자료 부족도 확인해야 하며 규제를 세게 한다고 항상 좋아지지 않습니다. 실제 업무에서는 검증 성능과 업무 비용을 함께 보고 방법을 선택합니다. 학습 손실 최소화와 실제 업무 성과를 구분하고 최종 평가 자료는 선택 과정에서 보호합니다.
