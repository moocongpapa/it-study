# RAG·검색 증강 생성의 전체 흐름

> **먼저 한 문장:** RAG는 필요한 외부 자료를 검색해 모델의 문맥에 넣고 그 근거로 답하도록 구성하는 방식입니다.

회사 규정이나 새 제품 문서처럼 모델이 모르는 자료로 답해야 할 때가 있습니다. 필요한 자료를 찾아 함께 주는 흐름을 알면 검색과 답변 중 어디가 잘못됐는지도 나눠 볼 수 있습니다.

## 먼저 알아둘 말

```learning
{"slug":"rag-retrieval","view":"words"}
```

## 작은 예로 이해하기

AI에게 우리 학교 도서관 운영 시간을 묻는다고 합시다. 먼저 최신 안내문을 찾고, 그 안내문을 질문과 함께 모델에 줍니다. 모델은 받은 자료를 근거로 답을 만듭니다. 이것이 RAG의 기본 흐름입니다. 잘못된 안내문을 찾으면 답도 틀릴 수 있으므로 검색 결과와 출처를 함께 확인합니다.

## 익숙한 장면과 연결하기

시험 전에 모든 내용을 외우게 하기보다 질문에 맞는 참고서를 찾아 펼쳐 주는 모습과 비슷합니다. 잘못된 페이지를 펼치면 답도 틀릴 수 있습니다.

**비유의 한계 — 이 점은 달라요:** 검색 자료를 넣었다고 사실성이 보장되지는 않습니다. 검색 누락·오래된 근거·권한 위반·근거를 잘못 해석하는 생성 오류를 나누어 확인해야 합니다.

## 직접 확인하기

필요 자료 검색 → 문맥에 넣기 → 근거 확인 순서로 읽어 보세요. 뒤의 과정에서 필요한 것이 앞에서 어떻게 준비되는지 찾습니다. 숫자는 읽는 순서이며 모든 상황이 정확히 세 단계라는 뜻은 아닙니다.

```learning
{"slug":"rag-retrieval","view":"explore"}
```

```learning
{"slug":"rag-retrieval","view":"recall"}
```

# RAG·검색 증강 생성의 전체 흐름 · 작동 원리

질문에 맞는 정책 조각을 고르는 작은 검색 예제입니다. 실제 RAG는 추출·인덱스·권한·최신성·생성과 평가를 함께 운영합니다. 문서 전체를 모델에 넣는 것과 목적은 비슷해도 실패 경계가 여러 개입니다.

## 전체 흐름부터 보기

```learning
{"slug":"rag-retrieval","view":"trace"}
```

## 예제와 내부 동작

아래 자료를 읽을 때 **입력 → 바뀌는 값이나 상태 → 결과**를 찾아보세요. 모르는 말은 밑줄 표시를 눌러 뜻을 확인할 수 있어요.

<!-- classroom-reference:start -->
## 읽기 전 길잡이

RAG는 필요한 외부 자료를 검색해 모델의 문맥에 넣고 그 근거로 답하도록 구성하는 방식입니다. 아래 예제는 외부 시스템에 연결하지 않는 작은 학습용 사례입니다. 입력, 처리 조건, 결과를 순서대로 살펴보세요.

1. 문서를 적절한 조각과 메타데이터로 저장합니다.
2. 질문과 권한에 맞는 근거를 검색합니다.
3. 근거와 함께 답을 생성하고 출처·불충분 처리 기준을 검사합니다.

## 예제로 확인하기

```python
# 키워드 검색만 보여 주는 예제이며 생성 모델은 호출하지 않습니다.
docs=[{"id":"policy-v2","text":"환불 기간은 7일"},{"id":"delivery","text":"배송은 2일"}]
query="환불"
hits=[d for d in docs if query in d["text"]]
assert hits[0]["id"]=="policy-v2"
print(hits)
```

## 결과를 해석하기

질문에 맞는 정책 조각을 고르는 작은 검색 예제입니다. 실제 RAG는 추출·인덱스·권한·최신성·생성과 평가를 함께 운영합니다. 문서 전체를 모델에 넣는 것과 목적은 비슷해도 실패 경계가 여러 개입니다.

## 실무에 옮기기 전

검색 자료를 넣었다고 사실성이 보장되지는 않습니다. 검색 누락·오래된 근거·권한 위반·근거를 잘못 해석하는 생성 오류를 나누어 확인해야 합니다. 실제 업무에서는 최신 지식 공급과 행동 학습을 구분합니다. 검색에 정답이 없을 때의 답 유보와 사람 연결을 설계하고 검색·생성 품질을 각각 측정합니다.

## 확인 질문

예제에서 환불 질의가 고르는 문서는?

**답과 이유:** 환불이라는 단어가 포함된 문서를 고르는 단순 검색입니다.

## 구체적인 사례와 확인 방법

같은 증상에도 원인이 여럿일 수 있어요. 먼저 발생 조건을 기록하고 증상을 재현할 수 있는지 확인하세요. **관찰한 증상 → 확인할 자료 → 수정 → 수정 후 확인(같은 조건으로 재검증)**을 연결해서 읽습니다.

## 1. 어떤 문제가 생겼나요?

가상 RAG가 존재하는 환불 규정을 찾지 못합니다.

## 2. 먼저 확인할 증거

## 3. 원인 가설

업데이트 문서가 누락되거나 질문에 필요한 조각이 검색되지 않았습니다.

## 4. 수정 방법

수집·분할·검색 단계별 원인을 수정하고 문서 버전을 표시합니다.

## 5. 재검증

정답 근거의 검색률과 생성 답의 근거성을 나누어 재평가합니다.

## 놓치기 쉬운 조건
